# Simple Blog App

A simple blog application built with Next.js App Router and TypeScript.

This project is created for learning purposes, focusing on routing, component structure, and basic UI styling using Tailwind CSS.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Features
- Blog list displayed on the homepage
- Dynamic routing for blog detail pages
- Bookmark functionality using Local Storage
- Simple and responsive layout

## Getting Started

Install dependencies:
```bash
npm install

Run the development server: 
npm run dev
Opern your browser and visit:
http://localhost:3000
